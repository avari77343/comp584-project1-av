# COMP-584 Project 1 — Email Campaign

Repository: `comp-584-project1-av`

This project extends the COMP-584 HW3 email campaign rather than replacing it.

## Project 1 Requirements

- Added a two-column component with new content.
- Added a three-column component with new content.
- Added responsive multi-column behavior so the columns stack on mobile.
- Adjusted multi-column text sizes for mobile.
- Added interactive buttons and descriptive text links.
- Added a keyframe animation using `translateY()` and `rotate()`; the animation does not use `opacity` or `scale`.
- Added the checked-box interaction technique using radio buttons, labels, and divs with `:checked` CSS selectors.
- Preserved the HW3 table-based email foundation: fluid outer table, fixed 600px inner table, presentation roles, responsive hero image, background-image text area, and accessible image/link practices.
- Added a separate Project 1 testing report PDF to `assets/`.

## Important testing note

Direct live testing in Gmail, Outlook, and Apple Mail requires sending the campaign through those clients/accounts. The included report documents the browser/mobile preview performed here and identifies client-dependent features that should be checked after deployment.
